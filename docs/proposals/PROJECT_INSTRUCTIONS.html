Project Instructions: Tantra Enterprise Proposals

Read this first in every Claude session opened in ~/tantra-enterprise-proposals.

The Job

A closer (Conor or Scott) finishes a 30-minute Tantra Enterprise Evaluation Call. The client was promised a written proposal within one business day. This project turns the call notes into that proposal.

How to Run It in a Claude Session

  1. The closer pastes the raw call notes (or the call transcript) into the chat, or saves them to proposals/<client-slug>/notes.md.
  2. Claude writes proposals/<client-slug>/notes.md in the field format from README.md: - situation: the client's own sentences, copied word for word from the notes. Never paraphrase a quote. If the notes hold no direct quotes, ask the closer for 2 or 3. - numbers: only numbers the client said. If a "today" or "target" is missing, ask; never estimate. - leak_stage: the one stage the closer named on the call. If the notes do not say, ask. - Leave payment_terms and start_date out unless Adi or the closer gave them.
  3. Run python3 generate.py proposals/<client-slug>/notes.md --paper a4 (or letter for US clients).
  4. Look at the PDF before saying it is done: render each page to PNG (python3 -c "import fitz; ..." or open it) and check for clipped text, a table split mid-row, or an amber FILL box.
  5. When every FILL box is filled, run again with --strict. It must pass.
  6. Hand the closer the PDF path. The closer sends it; Claude never emails, messages or uploads it.
  7. The closer logs it in the CRM sheet as proposal.sent with deal_value 9999 and the proposal_url (contract: ~/tantra-enterprise-webinar/deliverables/_shared/CRM_CONTRACT.md). The proposal's next step is Call 2, the Proposal Review, booked on the closer's own Cal.com link (from the funnel config); the proposal email the CRM sends carries the same link.

Rules (Adi's; breaking one fails the proposal)

  1. No em dashes or en dashes anywhere. Use a full stop, comma, colon, parentheses or "to".
  2. No AI slop. Every line earns its place. "I" is Adi, "you" is the client. The banned filler words are listed in tools/check.py.
  3. Proof comes only from config/proof.json (Growth Idea and FintechCircle, measured). Never add a client, a testimonial, a modelled pipeline figure, a guarantee, a bonus or a deadline. Never the fifty-million revenue claim in any form. Never name any other past client.
  4. Never type a price or an include into the template or the notes. They come from the funnel config.
  5. Enterprise is $9,999 with 1 year of platform access (never 10 years).
  6. Real proposals and notes live in proposals/ only, which git ignores. Never git add -f anything in it. Never paste client names, emails or numbers into commit messages, README files or chat summaries meant for others.
  7. Never push, open a PR or merge on any Usetantra/* repo. This repo is adisuja/tantra-enterprise-proposals, private.
  8. Never send, post, sign in anywhere or contact the client. The closer sends.
  9. Tools named in a proposal: Cal.com for booking, WhatsApp (never SMS), WebinarJam for webinars.
  10. Before every push: python3 tools/check.py must print 0 failures.

Changing the Template

  • Edit template/proposal.html. Slots are {{name}}; every slot is filled in generate.py (build()); the run stops if one is left.
  • Check both papers after any change: python3 generate.py examples/fictional-call-notes.md --paper both, then look at every page of both PDFs, and copy them over examples/fictional-proposal-a4.pdf and examples/fictional-proposal-letter.pdf.
  • Layout: the template mirrors Adi's proposal layout (/Users/adithyamurali/proposal design/proposal_template.html, a real client's proposal: read it for structure only, never copy anything from it). Keep its section order. After any change, rebuild the side-by-side images in compare/ (git-ignored) and look at them.
  • Brand: dark ground ink #0b0d12 with night #1a1033 cards, volt #6d4aff and iris #a78bfa accents, cyan #22d3ee for the client column, ember #c2410c only for the leak, amber only for FILL boxes. Fonts: Clash Display (headings), Satoshi, Inter. Logo: the current circuit-tree mark and wordmark in template/assets/ only. People: Adi's Kie.ai avatar only; clients get a monogram.
