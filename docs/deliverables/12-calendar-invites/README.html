Item 12: Cold Calendar Invite Templates

Two cold calendar invite variants for the weekly webinar, sent from Tantra calendar senders, with an A/B plan and an import CSV.

Claim to verify: both descriptions print {{webinar.title}}, and every candidate title carries "400+ founders" and "$100K to $300K a month". Neither has a source yet (PROOF_PACK.md section 2, BLOCKERS.md). Host lines use approved proof only: 250+ brands, 21+ countries, 10+ years.

What Is Here

File What it is
invites.md Both variants: the event title as Google Calendar shows it, and the description
ab-test-plan.md Split, sample size, metrics and the decision rule
calendar-import.csv Both variants in the Tantra calendar campaign shape, merge fields kept
build.py The single source of the copy. python3 build.py rewrites the md and CSV; python3 build.py --tantra --date YYYY-MM-DD writes calendar-tantra.csv for one session with config values filled and line breaks as <br> (Tantra's calendar description is HTML)
ab_decide.py Applies the decision rule to the counts
EVAL.md The done checklist, checked

Rules the Copy Follows

  • Titles are named like meetings, as the real invites in the library are ("Databricks teardown"): no "$", no "%", no "free", topic in the first 24 characters (the calendar grid cut). The webinar title, with its numbers, goes in the description.
  • Description: date, time and zone in words first; who it is for and what they leave with; an easy decline line; then the link.
  • Patterns reused: context/from-workshop-project/12-calendar-invites/ (Yes/Maybe line, framework bullets), 03-calendar-infra/calendar-invites.md (copy rules, limits) and the anonymised real invites in context/from-tantra-content/sources/library/real-outreach.ts (short descriptions, "Decline and you won't hear from us again").

Merge Fields

Field Filled from
{{first_name}} (variant B greeting only) master list; there when unknown, so it reads "Hi there,"
{{registration_link}} domains.funnel_domain + / + ?utm_source=calendar&utm_medium=invite&utm_campaign=enterprise-webinar&utm_content=cal_a (or cal_b)
{{event_date}}, {{event_date_words}} the session date of that week's campaign (--date), for example 2026-11-19 and "Thursday 19 November"
{{webinar.*}}, {{brand.*}} funnel-config.json

company is not used: guessed company names (for example "Thekbbcompany") would print in a stranger's calendar.

Merge support is unsettled. tantra-api.md says calendar invites take no merge tags, but the same file (line 254) lists an unverified usePersonalizedEvents setting, and deliverables/04-linkedin-templates/launch-kit.md (line 47) says Tantra AI-personalises calendar text. Until one test invite to an internal address proves per-guest text, build.py --tantra drops B's greeting line by default. If the test shows the first name with {{firstName}}, rebuild with --merge.

How To Load It Into Tantra (after Adi fills the config)

  1. python3 deliverables/12-calendar-invites/build.py --tantra --date <session date>.
  2. One Tantra calendar campaign per row of calendar-tantra.csv, built as a draft through /campaigns/draft (never /campaigns/create, which goes live at once): event.title, event.description, date, time, minutes, timezone, location; every calendar sender in both campaigns; each campaign gets its half of every sender's slice.
  3. Send 8 to 12 days before the session. Sender limits: 20 a day while a Workspace is under 60 days old, 50 after, never above 200.
  4. Read the result with ab_decide.py 48 hours after the session.

What Adi Must Fill (in deliverables/_shared/funnel-config.json)

domains.funnel_domain, webinar.title, webinar.first_date, webinar.start_time_local (with its zone in words, for example "11:00 New York time"), webinar.timezone.
