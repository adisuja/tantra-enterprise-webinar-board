Items 13, 14, 15a, 26, 20: the funnel pages (rebuilt to mirror the references)

A static review site for the Tantra Enterprise webinar funnel: registration (13), thank-you with VSL (14), indoctrination (15a), recording (26) and due diligence with four industry pages (20). Rebuilt 2026-11-05 after Adi rejected the first build: every page now mirrors the reference page he gave, section for section (spec: REFERENCE_MAP.md). Only the palette and type are Tantra's (volt, ink, night, lilac, iris; Inter only, the typeface usetantra.com uses), and the copy and proof are ours. Refined 2026-11-05 after Adi's feedback on the font and finish: Inter replaces Clash Display everywhere, every section was re-set on one type scale and an 8px grid, and every page was rebuilt mobile first (design system below). Every page is noindex,nofollow, has no trackers, and posts nowhere in review mode.

Design system (refined 2026-11-05)

All of it lives in src/assets/site.css as tokens at the top of the file. Mobile first: the base styles are for 360 to 430 wide, then 768, 1024, 1280 and 1600 and up.

Type. Inter only (usetantra.com's face), self-hosted variable woff2, weights 400 to 800. JetBrains Mono only for the tiny Step and Video labels, countdown units and FILL pills. Display type is Title Case, as in the webinar deck; no all-caps headlines. Every heading uses text-wrap: balance, so no orphans.

Spacing. 8px grid: 8, 16, 24, 32, 40, 48, 56, 64, 80, 96. Section padding clamp(64px to 128px). Page gutter 20px, 32px from 768, 40px from 1280. Content width 1200px (1280px from 1600); text blocks 640px to 760px; cards 880px to 1000px.

Colour (Tantra tokens). Ink #0b0d12 (dark bands, text), night #1a1033 (band gradient), paper #f7f8fb (light bands), volt #6d4aff (buttons, ticks), volt-deep #4b2fd6 (links, labels, case header), iris #a78bfa (accent on dark), lilac #f3f0ff (learn card, pills, bubbles), haze #c9c3ec. Body text #2a2f3a, muted #5b6472 (5.9:1 on white); on dark, text #e7e9ef and muted #aab1be. Every text pair meets WCAG AA; white on volt is 4.9:1.

Shape. Radii 10px to 12px (inputs, buttons, LinkedIn button), 14px (countdown boxes, pills), 16px (video), 24px (--r-lg) for every card: learn, case, host, step, quote, matrix, bonus, path and modal. Three shadow depths only (--sh-1 to --sh-3), always with a vertical offset; no hard offset shadows.

Components. - Buttons: 48px standard, 60px for the main CTA (full width on phones), Inter 600 to 700; hover lifts 1px, pressed sinks and darkens, focus shows a 3px iris or volt ring, disabled at half opacity. - Highlighter: soft lilac to iris gradient, ink text, small radius, never broken across a line in the hero. - Countdown: four separate boxes (Days, Hours, Mins, Secs) with a mono unit label; stacked label on phones, inline from 768. - Popup: a centred dialog with the volt gradient frame on desktop; on phones a full-height sheet with a fixed header, a scrolling body with scroll shadows and the Save my seat button pinned at the bottom. The sheet follows the visible viewport (visualViewport), so the keyboard never covers the button; checked headless by shrinking the viewport with a field focused. - Matrix: a white table card from 768; a stack of industry cards with one row per stage on phones. - Tap targets: every button, link button, field, checkbox row, matrix row link and nav item is at least 44px tall on phones. - Small text floor: no label is set below 12px. - Testimonial collage: three explicit columns written at build time, each quote placed in the shortest column so the columns end level; dark cards on a diagonal. Two columns at 640 to 1023, one on phones. - Matrix on phones: an industry with no case yet collapses to its name and "No case study yet". - Thank-you join control: a secondary outline button, "Find the email", which scrolls to the email card; it becomes the primary "Enter the live session" button once webinar.join_url is set. - Team monograms: two letters (Bk Bhaskar, Bh Bharath, Ne, Aq, Be, Am, Co, Sc), so no two look alike.

How the config works

Every title, date, time, link and price comes from deliverables/_shared/funnel-config.json. A value starting FILL_ renders as an amber pill naming the token. Fill it once, run ./publish.sh, and every page updates. The title falls back to webinar.working_title.

  • Countdowns: once webinar.first_date, webinar.start_time_local and webinar.timezone are set, every D/H/M/S box and every "Live session starts in" line counts down to that session. Cadence weekly rolls a past date forward to the next week's session. Until then the boxes read 00 and the pills say what is missing. There is never an evergreen timer. Checked with a test config (2026-11-12 11:00 America/New_York): boxes counted down, text timer read "7 days and 20 hours".
  • Live form: when integrations.register_worker_url and integrations.turnstile_site_key are both filled, Turnstile renders in the popup and the form posts to the Worker (item 17). Otherwise the review stub: no external script, no request.
  • Replay: every replay slot (the /recording/ hero and the due diligence Step 2 "Webinar Replay" row) reads webinar.replay_url. Nobody uploads it by hand: WebinarJam records each session and the replay link comes from WebinarJam through its API (the item 17 integration writes it into webinar.replay_url). Until then the slot is a designed placeholder with the FILL_REPLAY_URL pill. Note for the lead: the config comment on webinar.replay_url still describes it as the recording page URL; it should say "WebinarJam replay link (from the API)".
  • Videos: the VSL, the four /watch/ videos, the Program Deep-Dive and the case videos stay designed placeholders (play mark, title, "Video added once it is recorded", the FILL pill and the script file) until Adi records them; each fills from one config key.
  • Case stages: set 2026-11-05 in src/data/cases.json (Growth Idea scale, FintechCircle growth), each with a stage_basis note ("Estimated from filed Companies House accounts and published prices; see CASE_STAGE_RESEARCH.md"). The matrix puts a case in its stage column; a case with stage: null would show a FILL_STAGE pill and take the first open cell.
  • Values the shared config does not have yet, shown as local pills: FILL_DEEP_DIVE_VIDEO (media.deep_dive), FILL_GROWTH_IDEA_VIDEO and FILL_FINTECHCIRCLE_VIDEO (media.case_videos.<id>), FILL_REPLAY_CLOSES_AT (webinar.replay_closes_at, ISO), FILL_CHAPTER_TIMES, FILL_CLIENT_MESSAGE, FILL_TEAM_PHOTOS_AND_LINKS, FILL_BIO, Privacy and Fulfillment policy links. The lead adds the keys to the config when the values exist.

Form (registration popup)

Every CTA (4) opens the popup: dark overlay, volt frame, black panel, close button top right, Escape and overlay click close it. Fields in order: First name, Last name (optional), Work email, Company, WhatsApp number with a country-code picker (preselected from the visitor's time zone), Monthly revenue, "$10K+ to invest in the next 12 months?", then three unticked consent boxes (WhatsApp, AI reminder call, newsletter). Hidden: the visitor's IANA time zone.

Validation, states and payload are as before: ?state=invalid opens the popup with the inline errors, ?state=error opens it with sample details and the server error (resubmitting shows it again). The number is required only when the WhatsApp or call box is ticked. Payload: the webinar.registered body from CRM_CONTRACT.md, unchanged, with one addition the contract already lists: data.last_name, sent only when filled. phone is the dial code plus the number (for example +44 7700 900123).
