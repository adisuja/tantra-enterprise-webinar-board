15b Pre-Webinar Nurture (WhatsApp, Email, Vodex)

Every message a registrant gets from the moment they register until 10 minutes into the live session. The webinar is weekly, so everything is timed from webinar start, with rules for late registrants.

What Is Here

File What it is
SEQUENCE_MAP.md The timeline, who gets what, late-registrant and sending-hour rules, exits
COPY.md Every email and WhatsApp message in full, for reading
email.csv, whatsapp.csv, vodex.csv Import files, one per channel: step_id, trigger, offset_minutes, channel, template_name, subject, body, variables
emails/index.html The 13 HTML emails with a gallery (no confirmation email: WebinarJam sends it) (brand palette, current Tantra mark)
vodex/VODEX_CALL_SCRIPT.md Call script: opening, purpose, confirm, can't make it, calendar, voicemail; triggers and outcomes
vodex/agent-settings.json The two Vodex agent settings (greetingMessage, context, rules)
vodex/trigger-call.example.json Shape of the call request (invented person)
build.py The one source of copy. Edit it, run python3 build.py, and every CSV, email and COPY.md is rebuilt and checked
scheduler.py The timing rules in code. python3 scheduler.py --selftest runs 10 registration cases plus the WhatsApp window checks
nurture_lib.py Shared builder for 15b, 22 and 27: config tokens, WhatsApp template checks, HTML emails

How to Use It

  • Facts from funnel-config.json (host name, call length, session length, offer) are written in at build time. Change the config, rerun build.py.
  • Merge fields stay as {{name}} in the CSVs and emails: first_name, webinar_title, webinar_date_local, webinar_time_local, webinar_when_local, join_url, calendar_url, watch_url, video_*_url, booking_url, unsubscribe_url, company_address. Where each comes from: VARIABLES in nurture_lib.py. {{join_url}} is each registrant's personal WebinarJam link, merged from the contact (the register Worker, item 17, posts it on webinar.registered); the generic room link in config is only the fallback.
  • WhatsApp: bodies use positional variables ({{1}}, {{2}}) and the variables column says what each number is, so they can be submitted as WhatsApp Business templates (language English; category in the trigger column). Tantra sends from the number connected in Tantra; whether Tantra needs pre-approved templates is unverified, so the wording follows template rules either way.
  • Tantra: one campaign per timed message (email step plus WhatsApp step at wait 0), keyed by template_name; the runner adds each registrant at the time scheduler.py gives.

What Adi Must Fill (funnel-config.json)

webinar.title, day_of_week, start_time_local, timezone, first_date; webinar.join_url (the generic room link, a fallback only); domains.funnel_domain; media.indoctrination_videos (4); booking.round_robin_url; brand.legal_footer_address; integrations.vodex_agent_id and vodex_caller_number; the sending mailbox (not on growthclub.org, usetantra.com or free Gmail).

Notes for the Lead

  • WhatsApp window: every WhatsApp step, live-day reminders included, goes only 08:00 to 20:00 in the registrant's timezone; outside it only the email goes. For a 21:30 IST session, Indian registrants get no WhatsApp from the 1-hour reminder on. Waiving this for live-day steps is Adi's decision (BLOCKERS.md).
  • WhatsApp categories: Utility for reminders; Marketing for 15B-D3 and 15B-X1 (the trigger column of whatsapp.csv says which). 15B-R0 and 15B-X2 are kept to 3 and 2 variables.
  • 15B-L0 and 15B-L10 use WebinarJam's live attendance to skip people already in the room (item 17). Without it, L10 goes to everyone and its copy says "Already in? Ignore this."
  • 15B-C1 targets "opened no 15b email": needs open tracking in Tantra; if Tantra has no opens, use "clicked no link and no reply".
  • 15B-V4 mentions the Bonuses video but names no bonus: offer.webinar_bonus_stack is not approved yet.
