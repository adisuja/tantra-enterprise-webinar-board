Item 7: Facebook Group Announcement Posts

Adi's group list is not known yet, so this is a template set by group type. Once Adi sends his list, each group gets its own customised post from these templates.

Claim to verify: the first comment and the promo-thread version print {{webinar.title}}, and every candidate title carries "400+ founders" and "$100K to $300K a month". Neither has a source yet (PROOF_PACK.md section 2, BLOCKERS.md). The posts themselves use approved proof only: worked with 250+ brands across 21+ countries; Growth Idea (30 then 1,990 registrations, 98,000 of 99,859 reached by calendar invite; 1,990 registered, 321 live, 25 calls); FintechCircle as "a London fintech network" (10,000 to 30,000 outreach, 17 calls). Each client is named at most once per post.

Adi Steps

  1. Send the list of groups you are in. Open https://www.facebook.com/groups/joins/ (Facebook, Groups, "Groups you've joined", See all). Scroll to the bottom so every group loads. Paste each group's name and URL into the chat (or into group-tracker.csv, columns group_name and group_url). Then each group gets its customised post and tracker row.
  2. Post them yourself. Agents never post to Facebook. For each group: open the group URL from the tracker, click "Write something...", paste the post, click Post; if the placement is "first comment", paste the first comment under your post straight after.

Fill before posting: domains.funnel_domain, webinar.title, webinar.day_of_week, webinar.start_time_local in funnel-config.json.
