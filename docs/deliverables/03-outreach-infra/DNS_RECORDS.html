DNS Records per Domain (copy-paste blocks)

Written by build_infra_files.py. In the iFreeDomains panel: My Domains, Manage Domain, Manage iFreeDomains DNS. A Name of @ means leave the Name field blank (the root of the domain).

Two values come from Google Admin and replace the FILL_ text: the verification TXT (when you add the domain) and the DKIM key (ADI_STEPS.md step 6). Exactly one SPF record per domain: never add a second. DMARC reports go to dmarc@<the same domain>, an alias on the Workspace admin (ADI_STEPS.md step 5), so no outside domain has to consent.

1. northgatesessions.com (Workspace W1 strategywebinars (existing), pool P1)

Type  Name               Priority  Value
TXT   @                            FILL_WHOLE_VALUE_GOOGLE_SHOWS (starts google-site-verification=)
MX    @                  1         SMTP.GOOGLE.COM
TXT   @                            v=spf1 include:_spf.google.com ~all
TXT   google._domainkey            FILL_WHOLE_VALUE_GOOGLE_SHOWS (starts v=DKIM1; k=rsa; p=)
TXT   _dmarc                       v=DMARC1; p=none; rua=mailto:dmarc@northgatesessions.com; fo=1
