Item 4: LinkedIn Outreach Templates

24 sets: 6 senders (Adi, Aquila, Nelbin, Bharath, Bhaskar, Ben) x 4 campaign types (content engagement, InMail, connector, messenger). All of them invite people to the same weekly webinar, hosted by Adi. Every sender has their own wording for every message.

What Is Here

File What it is
OVERVIEW.md Start here: the 6 x 4 matrix, daily limits and ramp, audience splits, weekly schedule, proof trace, Tantra fit and Adi's steps
profiles/ One file per sender with all 4 sets: steps, waits, personalisation fields, daily limits, registration link and copy for every step
csv/ Tantra steps: content_engagement.csv, connector.csv, messenger.csv, inmail_followup.csv. Manual: inmail_manual_step1.csv (sent by hand in Sales Navigator). Columns: profile, campaign_type, step, delay_days, action, subject, message, char_count

build.py Builds everything above from one source. Fails on a note at 300+ characters, an action Tantra rejects, a message or opening shared by two senders, an unknown tag, a banned phrase or a dash
EVAL.md What "done" means for this item, with results

How To Use It

  1. Adi fills profiles.json and domains.funnel_domain in deliverables/_shared/funnel-config.json.
  2. Run python3 deliverables/04-linkedin-templates/build.py. It must print checks: 0 failures and no NOT READY line. Until then every link reads {{domains.funnel_domain}}/..., which Tantra would send as blank text, so load nothing before this.
  3. Run dedupe.py on the prospect lists (kept outside the repo) and split the output by owner_profile and campaign.
  4. In Tantra, build one draft campaign per sender per type (content engagement: one per post). Each CSV row is one step: delay_days is the wait after the previous step, action is the Tantra step action, message is the text. Pick that sender's LinkedIn account and set the account's start limits from their profile file.
  5. Send one test message before any launch. Add an internal contact (a team member) to the campaign, let one message go out, and check that {{firstName}}, {{company}} (and {{custom.post_topic}} on content engagement) filled and the link works. A blank tag means stop and fix the contact data first. Then remove the test contact and start.
  6. InMail: the sender sends step 1 from inmail_manual_step1.csv by hand in Sales Navigator, typing the first name and company in place of the tags. 5 days later, import only the people who did not reply into that sender's inmail_followup campaign.

Open Points

  • Merge tags. {{firstName}} and {{company}} follow Tantra's help page (https://usetantra.com/help/templates-and-ai/merge-tags-and-spintax). The older campaign kit used {{custom.company}}; the help page wins, and the test message in step 5 proves it. {{custom.post_topic}} is not on the help page; if it renders blank, type the phrase into that post's campaign.
  • Engager export. Tantra has no step that pulls a post's likers and commenters. How each post's engagers get exported is not settled.
  • Wait timing. Whether a wait after a connection request counts from the request or from the acceptance is unverified. Check the first draft's timeline.
  • Weekly cap. 180 a week (launch-kit.md, line 38) and 200 a week (linkedin.md, line 26) conflict. These files use 180.
  • Claims. No claim to verify is printed here: the copy never uses the webinar title, 400+ or the $100K to $300K range. Every number traces to PROOF_PACK.md (table in OVERVIEW.md).
