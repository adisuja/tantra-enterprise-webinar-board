Item 16: The Tantra Enterprise Webinar Deck

45 slides (65 states with tabs): 45 minutes of teaching and invitation, then 15 minutes of Q and A on the last slide. Rebuilt 2026-11-05 to mirror the reference recording slide by slide (Adi's rule 0); palette and type are Tantra's. Re-timed the same day: the offer in one slide (what it is, who it is for, the price, the next step) lands at minute 20 on slide 23, with the QR on slide 24, before the minute-25 early-leaver cutoff. Adi hosts alone (no co-host).

Open It Locally

open deliverables/16-deck/deck/index.html (or double-click it). Right arrow or Space: next (steps through a slide's tabs first). N: speaker notes. G or O: all slides. F: full screen. Add ?notes=1 to open with notes.

Rebuild after any change to the spec or config:

cd deliverables/16-deck/build
node --no-warnings build.mjs      # 45 slides, polls, chat count, FILL values still open
node --no-warnings probe.mjs      # must print "all 45 slides clean"
node --no-warnings shoot.mjs - /tmp/deckshots   # screenshots of every slide and tab
python3 compare.py /tmp/deckshots               # rebuilds ../compare/ (needs Pillow)

Then rerun node deliverables/21-engagement/export_from_deck.mjs so the engagement timings follow.
