Item 21: Webinar Engagement (Polls, Chat Prompts, Offer Cues, CRM Integration)

Path What it is
ENGAGEMENT_PLAN.md The 4 polls, 14 chat prompts with the moderator's exact lines, the WebinarJam offer box timings (cues at 20:00, 32:00 and 43:00; the first opens with the one-slide offer at minute 20 and closes at the minute-25 early-leaver cutoff), and the data path into the CRM sheet.
engagement.json Polls, prompts and cues with slide numbers and minutes, generated from the deck spec by export_from_deck.mjs. Never edit by hand.
map_engagement.py, columns.json WebinarJam chat log plus Cal.com bookings to webinar.poll_answered and webinar.cta_clicked (CRM_CONTRACT). Dry run by default; --send posts.
tests/ Fake example.com exports and a 53-check test.

Attendance (webinar.attended, webinar.no_show) is item 17's integration/import_attendance.mjs; this folder does not duplicate it.

Run

node deliverables/21-engagement/export_from_deck.mjs            # after any deck change
python3 -I deliverables/21-engagement/tests/test_map_engagement.py
python3 -I deliverables/21-engagement/map_engagement.py --chat ~/Downloads/<chat>.csv \
  --registrants ~/Downloads/<registrants>.csv --bookings ~/Downloads/<bookings>.csv \
  --date <YYYY-MM-DD> --start <HH:MM> --tz <Area/City> --out ~/tantra-private/21-engagement/<YYYY-MM-DD>

Add --send once the counts look right. The script refuses to write real people's data inside the repo.

What Adi Must Fill or Confirm

  • integrations.crm_webhook_url in funnel-config.json, and the CRM secret in $CRM_SHARED_SECRET or ~/.config/tantra/keys/crm-shared-secret (item 23 creates it).
  • booking.round_robin_url: the offer buttons and the chat link.
  • Who the moderator is each week (behind the scenes, never on camera; Adi hosts alone, no co-host).
  • First live session: confirm the chat log download and its headers, and that Cal.com keeps utm_content on bookings (ENGAGEMENT_PLAN, "Verify before the first live session").
