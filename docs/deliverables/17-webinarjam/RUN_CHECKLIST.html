Weekly Run Checklist: One Webinar, T Minus 7 Days to T Plus 1 Day

T is the start time (webinar.start_time_local, webinar.timezone). Owners: Adi (host), Support (the second presenter, webinar.moderator_name once set), Ops (whoever runs the scripts; commands run from deliverables/17-webinarjam/). WebinarJam: https://app.webinarjam.com/webinars

Export files with registrant data stay outside the repo (for example ~/Downloads/) and are deleted after the import.

T Minus 7 Days

  • [ ] Ops, WebinarJam: Edit the webinar, Schedules, add the date 4 weeks out, Add, Save. Four future sessions must always exist, or the registration function has nowhere to put people. Never delete or move a session with registrants.
  • [ ] Ops, browser: One test registration on our live registration page with an inbox you own. Pass: the thank-you page loads, the WebinarJam confirmation email arrives with a working join link, the CRM Webinar tab shows the row for the right date.
  • [ ] Adi, Google Calendar: Three internal blocks for the team, as in the SOP: Prep (T minus 30 min, 30 min), Live (T, webinar.duration_minutes min), Review (T plus 60 min, 60 min).
  • [ ] Adi: The deck (item 16) and the three offer cues from item 21 (20:00, 32:00, 43:00) are final. Click each offer's button link: it opens booking.round_robin_url.

T Minus 3 Days

  • [ ] Ops, WebinarJam and CRM: Reconcile both sides for this session. In the CRM sheet, open the Webinar tab, File, Download, Comma-separated values, save it outside the repo. Run node integration/register.mjs --reconcile --date <YYYY-MM-DD> --crm-csv ~/Downloads/<file>.csv, read the plan line, then run it again with --live. It reads WebinarJam's /registrants for the session: people only the CRM has are registered in WebinarJam only (no second webinar.registered), and people only WebinarJam has are posted to the CRM once with their join_url. Delete the CSV.
  • [ ] Ops: Worker logs (Cloudflare dashboard, the Worker, Logs) show no [register] warnings since last week. Any webinarjam: warning means someone is in the CRM without a link: the reconcile above fixes it.

T Minus 1 Day (T Minus 24 Hours)

  • [ ] Senders' lead (items 3 and 12): Export every Yes and Maybe RSVP from the calendar invite accounts as CSV with first_name, last_name, email. Two files: manual invites and automated invites, kept apart so the CRM can compare them (SOP step 21).
  • [ ] Ops: Dry run, then send: node integration/register.mjs --bulk rsvps-manual.csv --source calendar_manual then the same with --live; repeat for rsvps-auto.csv with --source calendar_auto. The summary line must show 0 warnings.
  • [ ] Ops, WebinarJam: Registrants count for the session went up by about the number of rows.

T Day

  • [ ] T minus 3 h, Adi and Support: Webinars, Your links, Presenters: each opens their own presenter link on a laptop, checks camera, microphone and screen share. Enable third-party cookies if the room will not load.
  • [ ] T minus 75 min, Ops: Second RSVP batch (new Yes and Maybe since T minus 24 h), same two commands with --live. Then the same reconcile command once more, so late page registrants who missed WebinarJam get their link before the start.
  • [ ] T minus 30 min, all, Prep block: Registration count vs target, who handles which questions, the three offer cues.
  • [ ] T minus 15 min, Adi: In the room before the start; Support logged in and watching chat.
  • [ ] T, Adi: Start the broadcast. Support follows the chat rules in EVENT_CONFIG section 7.
  • [ ] Minutes 20:00, 32:00, 43:00, Support: Launch offer cta1_soft as slide 23 (the offer in one slide) appears (close at 25:00), then cta2_checkpoint (close at 35:00), then cta3_main (keep open to the end). Launch each poll when Adi asks it.
  • [ ] Minute webinar.presentation_minutes, Support: Hand Adi the question list.
  • [ ] T plus 60 min, Adi: End the broadcast.
  • [ ] T plus 60 min, all, Review block: Attendance vs registrations, how many stayed past minute webinar.retarget_cutoff_minute, calls booked, poll results (Log, Poll results), one change for next week.
  • [ ] T plus 120 min, Ops: Registrants, this webinar and session, Go, Export, Export all registrants (not "attendees only", which drops the no-shows). Then: node integration/import_attendance.mjs --csv ~/Downloads/<export>.csv --date <YYYY-MM-DD> --start <HH:MM> --tz <Area/City> --out /tmp/events.json Check the printed "columns used" and counts, then run it again with --live. Item 22 starts each person's track when this arrives. Delete the export file.

T Plus 1 Day

  • [ ] Ops, WebinarJam: Your links, Replay, pick the session, download the recording for item 26.
  • [ ] Ops, CRM: The Webinar tab for this date has a segment on every row (stayed_to_offer, early_leaver or no_show) and retarget_until on early leavers and no-shows.
  • [ ] Adi: The change agreed in the Review block is assigned for next week.
