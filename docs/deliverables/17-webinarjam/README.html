For the Lead

  1. funnel-config.json: add integrations.turnstile_site_key (FILL_TURNSTILE_SITE_KEY). register_worker_url, webinarjam_webinar_id, webinarjam_sender_email and moderator_name are already there.
  2. Item 13, the exact snippet. The page must post to the Worker, never to the CRM. In the registration form, just above the submit button:
<div class="cf-turnstile" data-sitekey="{{integrations.turnstile_site_key}}" data-action="register"></div>
<script src="https://challenges.cloudflare.com/turnstile/v0/api.js" async defer></script>

In site.js, replace the stub setTimeout(...) inside the submit handler with:

var tokenEl = form.querySelector('[name="cf-turnstile-response"]');
var token = tokenEl ? tokenEl.value : '';
if (!token) { btn.disabled = false; btn.textContent = 'Save my seat'; serverErr.hidden = false; return; }
body.turnstile_token = token;
body.data.timezone = body.data.timezone || Intl.DateTimeFormat().resolvedOptions().timeZone;
fetch(F.register_worker_url, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(body) })
  .then(function (r) { return r.json(); })
  .then(function (j) {
    if (!j.ok) throw new Error(j.error || 'failed');
    try { sessionStorage.setItem('tantra_first_name', body.data.first_name); } catch (e) {}
    location.href = j.redirect || F.thank_you_path;
  })
  .catch(function () {
    if (window.turnstile) window.turnstile.reset();
    btn.disabled = false; btn.textContent = 'Save my seat'; serverErr.hidden = false;
  });

F.register_worker_url is integrations.register_worker_url. The Worker answers {"ok":true,"redirect":"<funnel domain>/thank-you/"}, or 400 (bad body), 403 (Origin or captcha), 502 (neither WebinarJam nor the CRM saved the person). 3. Item 21: WebinarJam keeps poll results per session only and cannot report offer clicks per person, so webinar.poll_answered and webinar.cta_clicked need chat or a form. Item 18-19: keep the offer links' utm_content on booking.created. Item 22: the attendance import its TRACKS.md calls "item 27's script" is integration/import_attendance.mjs. Item 1: WebinarJam titles stop at 70 characters; the third-ranked title is 74. 4. Item 23: its sheet menu has its own WebinarJam import, which reads a two-part time like 05:30 as minutes:seconds. This importer refuses two-part values until minutes_is is set. Once the first real export settles it, set both the same way.
