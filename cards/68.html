WhatsApp preview images (card 42)

18 images, one for every WhatsApp message the Tantra CRM sends: 13 webinar messages (Business API) and 5 sales messages (Adi's WhatsApp account).

All images: https://tantra-funnel-map.growthcluborg.workers.dev/wa-images/

How they are made

  • art/: four background scenes from Kie.ai (gen_art.py, nano-banana-pro, 72 credits, about $0.36). No text or logos come from the model.
  • images.json: the words on each image and the message each one goes with.
  • build.mjs: each image is an HTML page (Inter, Tantra palette, the real Tantra logo) rendered by headless Chrome. Output is out/<key>.jpg, 1600 x 837 (1.91:1, Meta's ratio for image headers), about 160 KB.
  • gallery.py: writes the gallery page in the funnel map.

How they are sent (Tantra CRM, repo adisuja/tantra-crm, PRs 13 to 15)

  • Where they live: the images are served from https://crm-api.usetantra.com/media/wa/, with a list at index.json.
  • Choosing one: each WhatsApp step in a sequence has a Preview image picker.
  • WhatsApp account (Unipile): the image goes out with the text as its caption. If WhatsApp refuses the image, the text still goes out.
  • Business API inside the 24-hour window: the image is attached to the free text.
  • Business API templates:
  • Meta cannot add an image to a template that was already submitted, so each template has an image version, <name>_img. It has the same text and an image header that points to the library.
  • All 12 image versions were submitted to Meta on 9 November.
  • A step sends the image version once Meta approves it, and the text version until then.

Changing an image

  1. Edit images.json.
  2. Run node build.mjs and python3 gallery.py.
  3. Copy out/*.jpg into the CRM worker's public/media/wa/ and deploy the worker.
  4. Run bash ../39-funnel-map/publish.sh.

Approved templates pick up the new image without a new Meta review, because the header URL ends in a variable.
