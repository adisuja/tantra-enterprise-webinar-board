Card 46: the funnel live on webinar.sellwithtantra.com

Live since 8 November 2026: https://webinar.sellwithtantra.com/

What runs there

  • Worker tantra-webinar-site (growthcluborg Cloudflare account), custom domain webinar.sellwithtantra.com. It serves the built pages from deliverables/13-15a-26-20-pages/site and the form endpoint /api/register. The Google Workspace mail records on the same name (MX, SPF, DKIM) are untouched.
  • Registration form: Cloudflare Turnstile checks every sign-up (widget "Tantra webinar registration", keys in ~/.config/tantra/keys/turnstile-webinar.env).
  • D1 database tantra-webinar-registrations: every webinar.registered and webinar.survey_completed event is stored there with email, phone, UTM fields, the survey answers and the plan link, so nobody is lost while WebinarJam (card 17) and the CRM (card 41) are not switched on. GET /api/admin/export (Bearer key in ~/.config/tantra/keys/webinar-site.env) lists them for the replay into both.
  • RevOps OS buy button switched off until the pack is attached (card 45). The live checkout link is kept as offer.vip_checkout_url_live in funnel-config.json: copy it into offer.vip_checkout_url, rebuild and redeploy to switch it on.
  • Every outreach link (calendar invites, cold email, LinkedIn templates and profiles, company page, Facebook group, content batches) now points at the domain.

Tested on 8 November

  • Every page and state on desktop and phone: no errors, no broken assets.
  • The case explorer click test (148 checks) on the live domain.
  • A full run on a test copy with Cloudflare's official Turnstile test keys: register, 22 survey screens, upsell, No thanks, confirmation with the plan link, the calculator from that link. Both events stored in D1 with the right fields; the test rows and the test copy were deleted.
  • The API refuses a registration without Turnstile, unknown events, and the export without the key.
