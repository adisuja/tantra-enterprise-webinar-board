WhatsApp scheduler (board card 36)

Posts the webinar reminders into the Tantra Community on WhatsApp, for free. Built on Baileys (MIT), which links an admin number as a device, the way WhatsApp Web does.

Why this and not something else

Option Posts into a Community / Announcements? Cost Notes
Official WhatsApp Cloud API, Groups API No Per message Needs an Official Business Account, groups capped at 8, no Communities
Unipile (linked account) Yes, groups are ordinary chats From 49 EUR a month (up to 10 accounts) Same unofficial QR-linked method as this tool, hosted for you
Blueticks Chrome extension Yes, any chat in WhatsApp Web Free for 3 scheduled messages at a time Sends only while Chrome is open on WhatsApp Web; paid cloud sending
This tool (Baileys on the Mac) Yes Free Runs every minute from launchd; connects only when a post is due

Every route that posts into a Community is unofficial and outside WhatsApp's terms. Link a spare admin number, never a personal one, and keep the volume low (4 posts a webinar).

Set up (once)

  1. npm install
  2. Make the spare number an admin of the Tantra Community, then node wa.mjs link and scan the QR with that phone (WhatsApp, Settings, Linked devices, Link a device). Or node wa.mjs link --phone 447700900000 for an 8-character pairing code.
  3. node wa.mjs groups finds the Tantra Community, its Announcements group and THE COMMUNITY.
  4. node wa.mjs plan --weeks 4 writes schedule.json: the 15b WhatsApp copy for tomorrow, 1 hour, 15 minutes and live now, as group posts. A post waits (HOLD) until every link it needs is in funnel-config.json (the WebinarJam room link).
  5. node wa.mjs send-due --dry-run shows what would go out now. Then ./install-launchd.sh.

Send one message now: node wa.mjs post announcements "text" or node wa.mjs post community "text".

Where things live

  • Session keys, targets and the sent log: ~/.config/tantra/whatsapp/ (outside the repo, never committed).
  • The schedule: schedule.json here (no secrets). Rebuild it with plan whenever the date or the copy changes.
  • Log: ~/.config/tantra/whatsapp/scheduler.log.

The Mac must be awake at post time. If that becomes a problem, the same script runs unchanged on any always-on machine with Node.
